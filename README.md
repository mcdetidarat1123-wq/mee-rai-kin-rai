# มีไรกินไร 🧊

ถ่ายรูปวัตถุดิบในตู้เย็น ให้ AI (Claude) ช่วยแยกรายการวัตถุดิบ แล้วคิดเมนูที่ทำได้จริง 4 แบบ พร้อมแคลอรี่ สารอาหาร และขั้นตอนทำทีละสเต็ป

โครงสร้างโปรเจกต์:
- `index.html`, `style.css`, `app.js` — หน้าเว็บฝั่งผู้ใช้ (ไม่ต้อง build)
- `api/analyze.js` — เรียก Claude วิเคราะห์รูปวัตถุดิบ
- `api/menus.js` — เรียก Claude คิดเมนู 4 แบบพร้อมสูตรทำ

API Key ของคุณจะถูกเก็บไว้ในเซิร์ฟเวอร์เท่านั้น (ผ่าน Environment Variable) ผู้ใช้ที่เข้าเว็บจะไม่เห็น Key เลย

---

## วิธี Deploy ให้คนอื่นเข้าใช้ได้จริง (ฟรี ผ่าน Vercel)

### ขั้นตอนที่ 1 — สมัคร GitHub (ถ้ายังไม่มี)
ไปที่ https://github.com/signup สมัครฟรี ใช้อีเมลที่มีอยู่ได้เลย

### ขั้นตอนที่ 2 — สร้าง Repository แล้วอัปโหลดไฟล์
1. ไปที่ https://github.com/new ตั้งชื่อ เช่น `mee-rai-kin-rai` เลือก **Private** หรือ **Public** ก็ได้ แล้วกด **Create repository**
2. ในหน้า repo ที่สร้างเสร็จ กด **"uploading an existing file"**
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `style.css`, `app.js`, `package.json`, `vercel.json`, `.gitignore`, `.env.example`, โฟลเดอร์ `api/`) ไปวาง แล้วกด **Commit changes**

> อย่าอัปโหลดไฟล์ `.env` (ถ้าคุณสร้างไว้) — ใส่ API Key ผ่านหน้าเว็บ Vercel แทนในขั้นตอนถัดไป

### ขั้นตอนที่ 3 — สมัคร Vercel แล้วเชื่อมกับ GitHub
1. ไปที่ https://vercel.com/signup แล้วเลือก **Continue with GitHub** เพื่อสมัครด้วยบัญชี GitHub เดียวกัน
2. หลัง login กด **Add New... > Project**
3. เลือก repository `mee-rai-kin-rai` ที่เพิ่งสร้าง แล้วกด **Import**
4. ในหน้า "Configure Project" เปิดส่วน **Environment Variables** แล้วเพิ่ม:
   - Name: `ANTHROPIC_API_KEY`
   - Value: (วาง API Key ของคุณจาก https://console.anthropic.com/settings/keys)
5. กด **Deploy** รอประมาณ 1 นาที

### ขั้นตอนที่ 4 — เสร็จแล้ว!
Vercel จะให้ลิงก์ถาวรมา เช่น `https://mee-rai-kin-rai.vercel.app` — เอาลิงก์นี้ไปแชร์ให้ใครก็เปิดใช้ได้เลย ไม่ต้องมีบัญชี ไม่มีลิมิตจากฝั่งเรา (มีแค่ลิมิตตามเครดิต API ของคุณเอง)

ทุกครั้งที่แก้ไฟล์แล้วอัปโหลดขึ้น GitHub ใหม่ Vercel จะ deploy เวอร์ชันล่าสุดให้อัตโนมัติ

## เรื่องค่าใช้จ่าย

แอปนี้เรียก Claude API จริงทุกครั้งที่มีคนถ่ายรูปหรือคิดเมนู ซึ่งมีค่าใช้จ่ายตามการใช้งานจริง (pay-as-you-go) จากบัญชี Anthropic ของคุณ ไม่ใช่ฟรีไม่จำกัด — แนะนำให้ตั้ง **Usage limit / budget alert** ไว้ที่ https://console.anthropic.com/settings/limits เพื่อกันไม่ให้มีคนใช้แล้วยอดพุ่งเกินคาด

## ข้อมูลผู้ใช้เก็บไว้ที่ไหน

เมนูที่บันทึกไว้ และประวัติตู้เย็น เก็บไว้ใน **เบราว์เซอร์ของผู้ใช้แต่ละคนเอง** (localStorage) ไม่ได้ส่งเข้าฐานข้อมูลกลาง แปลว่าถ้าผู้ใช้ล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหายไป — ถ้าต้องการให้ข้อมูลอยู่ถาวรข้ามอุปกรณ์ ต้องเพิ่มระบบฐานข้อมูล/ล็อกอิน ซึ่งแจ้งมาได้ถ้าต้องการให้ช่วยต่อ

## รันทดสอบในเครื่องตัวเอง (ไม่บังคับ)

ต้องมี Node.js ≥ 18 และ Vercel CLI:
```
npm i -g vercel
vercel dev
```
แล้วสร้างไฟล์ `.env` ใส่ `ANTHROPIC_API_KEY=...` ตามตัวอย่างใน `.env.example`
